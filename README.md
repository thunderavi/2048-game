# 2048 - React

React implementation of the 2048 game (GUI).

## Features
- Configurable board size (3×3 to 6×6)
- Arrow-key controls and Restart (R)
- Merging rules and scoring
- Functional programming style: pure helpers and immutable board updates
- Win (reach 2048) and Lose detection
- Easy to extend (undo, animations, AI)

## Installation
```bash
git clone <your-repo-url>
cd 2048-react
npm install
npm run dev      # open http://localhost:5173
